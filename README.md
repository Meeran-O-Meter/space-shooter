## The basic idea
This shmump was inspired by retro arcade style from the 90's, _I remember them just like yesterday. Why, I was still in me mother's womb, not to set foot onto this earth till the next 2 decades._ I followed Godot documentation, and it obviously took quite a while for me to acclimate to Godot.
In case you're **that** uncultured though, a retro classic shmump is a game where you dodge aliens invaders, asteroids, and bosses as a spaceship. However, as a beginner, I stripped it down to the core, which meant just basic game functionality, and no immense algorithm to spawn them bosses and asteroids.
